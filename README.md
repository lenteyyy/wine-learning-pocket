# 万物学习 · 葡萄酒

三语葡萄酒学习工具。静态网页，打开 `index.html` 即可使用；学习进度与收藏保存在当前浏览器。

酒单内容参考用户提供的重庆康莱德、Club Millésime 酒单及国泰航空公开酒单，供应可能变化。酒瓶照片由网页直接链接第三方来源，版权属于各自权利人；图片及年份可能变化，第三方服务器也可能阻止加载。未确认对应酒款的图片不展示。仓库代码的 MIT 许可不适用于第三方图片或商标。

学习间隔计算复用 [台语小辞典](https://github.com/lenteyyy/taigi-pocket)；`legacy/` 保存其网页代码，供后续适配。旧版其他数据和音频并非此工具运行所需，未包含在内。
